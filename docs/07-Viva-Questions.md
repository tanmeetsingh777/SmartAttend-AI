# SmartAttend AI - Viva Voce Questions & Answers (25+ Questions)

### Q1: Why did you choose the MERN tech stack for the core web application?
**Answer:** MERN (MongoDB, Express, React, Node.js) provides a full JavaScript ecosystem, non-blocking asynchronous I/O for high concurrency, scalable JSON data handling with MongoDB, and a reactive component-driven UI with React.

### Q2: Why use Python for the AI microservice instead of Node.js?
**Answer:** Python is the industry standard for computer vision and machine learning due to mature numerical libraries (NumPy, OpenCV) and native bindings for deep neural network execution engines.

### Q3: Why FastAPI over Flask or Django for the AI service?
**Answer:** FastAPI is asynchronous (`async/await`), provides automatic OpenAPI schema generation, fast performance built on Starlette and Pydantic validation, and minimal overhead for microservices.

### Q4: What is the difference between Face Detection and Face Recognition?
**Answer:**
- **Face Detection**: Locating where a face is present in an image (bounding box `[x, y, w, h]` and facial landmarks).
- **Face Recognition**: Identifying WHO the detected face belongs to by comparing its feature vector against enrolled student embeddings.

### Q5: What is a Facial Embedding?
**Answer:** A facial embedding is a compact, 128-dimensional numerical vector representing deep facial feature representations (distance between eyes, nose bridge shape, jawline geometry) generated by a pretrained neural network.

### Q6: How are facial embeddings compared mathematically?
**Answer:** By computing the **Cosine Similarity** between two 128-dimensional vectors \( \mathbf{u} \) and \( \mathbf{v} \):
\[ \text{Cosine Similarity} = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\| \|\mathbf{v}\|} \]
If the angle is small, the dot product approaches 1.0, indicating the same person.

### Q7: What pretrained models are used in this project?
**Answer:** OpenCV Zoo's official **YuNet** (`FaceDetectorYN`) for face detection and **SFace** (`FaceRecognizerSF`) for feature embedding extraction in ONNX format.

### Q8: What is the calibrated similarity threshold?
**Answer:** SFace cosine similarity threshold is set to `0.363`. Any score above `0.363` indicates a positive match.

### Q9: What happens when an unknown face appears in front of the camera?
**Answer:** The maximum similarity score against candidate embeddings falls below the `0.363` threshold. The AI service returns `status: "unknown"`, and no attendance record is created.

### Q10: How does the system prevent duplicate attendance entries?
**Answer:** On two levels:
1. **Application Logic**: Express checks if an attendance record exists for the active session before insertion.
2. **Database Constraint**: A MongoDB unique compound index `{ sessionId: 1, studentId: 1 }` prevents duplicates even under race conditions.

### Q11: Why is MongoDB chosen over relational databases like MySQL?
**Answer:** MongoDB's flexible document structure easily accommodates nested biometric metadata (`faceEnrollment`), scales horizontally, and operates natively with JSON.

### Q12: How does JWT authentication work?
**Answer:** Upon valid credentials, Express signs a JSON Web Token with the user ID and secret key. The React frontend attaches this token in the `Authorization: Bearer <token>` header for subsequent protected API requests.

### Q13: How is biometric privacy protected in SmartAttend AI?
**Answer:**
- Raw webcam photos are NOT stored in MongoDB or disk.
- Embeddings are 128-dim mathematical floats, non-reversible into original face photos.
- Embeddings are excluded (`select: false`) from standard API queries and never exposed to the frontend.

### Q14: What happens if the Python AI service goes offline?
**Answer:** The Express backend catches the connection failure (`ECONNREFUSED`), gracefully logs the error, and alerts the user on the frontend without crashing the web application.

### Q15: How does webcam frame capture work in HTML5/React?
**Answer:** Using `navigator.mediaDevices.getUserMedia({ video: true })` bound to a `<video>` element, rendered to a hidden HTML5 `<canvas>`, and exported as a Base64 JPEG data URL.

### Q16: How are camera tracks cleaned up when leaving a page?
**Answer:** In the React `useEffect` cleanup return hook, `stream.getTracks().forEach(track => track.stop())` is called, ensuring the browser camera LED turns off immediately.

### Q17: How does Express communicate with the Python FastAPI AI service?
**Answer:** Through internal HTTP POST requests using Axios, authenticated via an internal `X-AI-Secret` header.

### Q18: What validation checks are performed during face enrollment?
**Answer:**
1. Detection check (0 faces -> error).
2. Multiple faces check (>1 faces -> error).
3. Image quality check (blurriness via Laplacian variance < 30, darkness < 30, min face size < 40px).

### Q19: Why use ONNX format for AI models?
**Answer:** ONNX (Open Neural Network Exchange) provides cross-platform interoperability, optimized C++ inference execution in OpenCV, and removes framework-specific overhead.

### Q20: How is role-based authorization implemented?
**Answer:** Custom Express middleware `authorize('admin', 'teacher')` checks `req.user.role` from the decoded JWT payload before executing route handlers.

### Q21: How are attendance percentages calculated in reports?
**Answer:**
\[ \text{Attendance Percentage} = \frac{\text{Present Classes}}{\text{Total Sessions}} \times 100 \]

### Q22: What is the purpose of the seed script?
**Answer:** `node seed.js` populates MongoDB with initial university demo entities (Admin, Teacher, BCA-3A, BCA-3B, Students, and historical session logs) for immediate demonstration without manual setup.

### Q23: Why not generate fake face embeddings in demo data?
**Answer:** Fake embeddings degrade recognition reliability. Real embeddings must be generated through the genuine YuNet + SFace pipeline during actual face enrollment.

### Q24: What are the current system limitations?
**Answer:** Webcams require adequate lighting; extreme side-profile angles (>45 degrees) reduce detection accuracy.

### Q25: What future improvements can be added?
**Answer:** Liveness detection (blink/3D depth estimation), RTSP CCTV stream integration, and GPU TensorRT acceleration.
